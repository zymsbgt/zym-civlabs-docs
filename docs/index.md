# Zym's CivLabs Wiki

## Welcome to Zym's CivLabs Wiki!

This wiki documents the differences between the OG CivLabs plugin (by ShotRush) and Zym's CivLabs.

## Getting Started

If you are new here check out the [New Player Guide](https://wiki.civlabs.org/books/player-guides/page/new-player-guide) (External Link), as this provides many important links and a quick guide on how to survive your first nights. If you want mod recommendations, I suggest checking out [CivLabs Wiki's List of Recommended Mods](https://wiki.civlabs.org/books/information-of-wiki/page/recommended-mods) (External Link). Do note that metagaming is allowed in Zym's CivLabs.
